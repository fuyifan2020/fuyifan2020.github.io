embedding（嵌入）：将文字/图片/视频等转换为向量的过程。为了计算两个对象的相似度，先对对象进行embedding，再对embedding向量计算Cosine Similarity（余弦相似度），余弦相似度越高，语义越相似。

embedding原理:对于一句话来说，1.先将文字切成token，再转换为数字ID。例如“一二三”，先将句子拆为“一”“二”“三”，再将对应token转换为对应数字ID。2.根据数字ID查表（表在模型内部，已训练出来的），每个数字ID对应一个高维向量（本质是矩阵查表，从ID到向量的映射表）。3.对于上下文模型，会再将初始静态向量推送多层自注意网络，根据前后文重新调整每个token的向量。
那对于一句话的向量，主流上，是将每个token的向量Pooling（池化）得到的。例如：Mean Pooling（平均池化），所有token向量逐位求平均。

余弦相似度算法： cos(A, B) = (A · B) / (|A| × |B|)
伪代码：
import numpy as np
  def cosine(a, b):
      return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))
  sim = cosine(vec_句子A, vec_句子B)
